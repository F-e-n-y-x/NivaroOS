This NivaroOS server encrypts its dashboard on your home network with its own certificate. Install it once on each device and the browser shows the connection as secure. The certificate only works for this server's local names and home-network addresses, never for websites on the internet.

Windows

  1. Open the downloaded nivaroos-ca.crt and choose Install Certificate.
  2. Pick Current User, then Place all certificates in the following store > Trusted Root Certification Authorities.
  3. Finish, accept the warning, and restart the browser.

macOS

  1. Open the downloaded file; Keychain Access adds it to login.
  2. Double-click "NivaroOS local CA", open Trust, set When using this certificate to Always Trust.

iPhone and iPad

  1. Open this page in Safari and tap Download certificate, then Allow.
  2. Settings > Profile Downloaded > Install.
  3. Settings > General > About > Certificate Trust Settings: switch on "NivaroOS local CA".

Android (browsers)

  1. Download the certificate.
  2. Settings > Security > More security settings > Encryption & credentials > Install a certificate > CA certificate, and pick the file.

The NivaroOS app doesn't need this: it shows the fingerprint and asks you once.

Firefox (any system)

  1. Settings > Privacy & Security > Certificates > View Certificates > Authorities > Import.
  2. Tick Trust this CA to identify websites.

Linux (Chrome, system)

sudo cp nivaroos-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates. Chrome on Linux: Settings > Privacy and security > Security > Manage certificates > Authorities > Import.

After installing, open the dashboard with https:// and sign in once more (browsers keep separate sign-ins for http and https).
